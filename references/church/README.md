# Published reference sequences

Selected input panels and specimen metadata from
https://github.com/shchurch/Physalia_spatiotemporal_patterns/tree/main/phylogenetics
at commit `d08f0edf4d819e21c85705e4965de71673808dec`.

Files are unmodified copies; the analysis selects the named cohort and six
utriculus specimens from these panels. The original LICENSE is included here.
Research content is attributed to the authors of *Seasonality, distribution,
and morphology of bluebottles (Physalia) in the world's oceans*. GenBank records
retain their source accessions and are subject to NCBI terms. See LICENSE for
the full distinction between source code, research content and third-party data.
